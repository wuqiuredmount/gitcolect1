## 二、命名规范

公式：`[时间] + [地域] + [类别] + [范围限定]`

- **时间**：`2026年1月` / `2026春节` / `暑期`
- **地域**：`全国` / `四川省` / `成都周边`
- **类别**：`运动赛会` / `4A级景区` / `非遗项目`
- **范围限定**：让边界清晰的后缀

判定：一个新分组名，若不能一眼看出「覆盖什么、不覆盖什么」，就重写。
